## ⚡ About

I'm a **Software Engineering student** focused on AI engineering, intelligent systems, and machine learning.

I enjoy building systems where AI does more than generate text — systems that **understand, retrieve, reason, plan, interact, and automate**.

```
AI Systems

├── 🔎 RAG & Semantic Retrieval

├── 🎭 Multimodal AI
├── 👁️  Computer Vision
└── 🧑‍🤝‍🧑 Human–AI Interaction
```

> 🛠️ **Build it. Break it. Understand it. Build it better.**
